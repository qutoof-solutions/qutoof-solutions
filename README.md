# Qutoof Solutions — قطوف للحلول الرقمية

موقع تعريفي سريع ومتجاوب، بواجهتين EN/AR. يستخدم Vite للبناء، وLenis للتمرير السلس، وMotion للكشف المتدرج. لا يحتاج الموقع إلى خادم خلفي أو قاعدة بيانات، ولا يعرض باقات أو أسعارًا ولا يجمع الاستفسارات بنموذج؛ أزرار التواصل تفتح WhatsApp مباشرة.

## التطوير والبناء

```bash
npm ci
npm run dev
npm run build
npm run preview
```

يفتح خادم التطوير على المنفذ 3000. ملفات الإنتاج الثابتة في `dist/`، وملف بيان المسارات المصدر في `public/manus-routes.json`.

## بنية الملفات

- `assets/images/logo.png` — الشعار المرفق كما هو.
- `assets/images/logo-transparent.png` — نسخة PNG شفافة مقصوصة للشعار؛ الأصل محفوظ دون تعديل.
- `public/assets/images/logo.png` — نسخة الشعار التي ينسخها Vite إلى إصدار الإنتاج.
- `public/assets/images/logo-transparent.png` — النسخة الشفافة المستخدمة في هيدر الموقع.
- `public/assets/images/portfolio/` — صور معاينة حقيقية لصفحات الديمو التسع.
- `css/main.css` — لوحة العلامة والتصميم المتجاوب وRTL.
- `css/animations.css` — الكشف والحركة.
- `js/main.js` — سلوك الصفحة والفلاتر والتمرير وروابط التواصل.
- `js/lang.js` — المحتوى الإنجليزي والعربي ومبدل اللغة.
- `js/projects.js` — روابط الأعمال وفئاتها وأسماؤها وملفات الصور.

## قبل الإطلاق

- قيمة WhatsApp في `js/main.js` ما زالت قناعًا مؤقتًا `9665XXXXXXXX`. استبدلها برقم قطوف الفعلي بصيغة `wa.me` من دون `+` أو مسافات؛ تستخدم أزرار التواصل في الهيدر وHero وقسم التواصل والتذييل والزر العائم هذا المصدر. بطاقات الأعمال تفتح مواقع الديمو المرتبطة بها.
- البطاقات التسع هي مواقع تجريبية حية أرسلها المستخدم، وليست ادعاءات نتائج لعملاء. ثلاثة أسماء ظاهرة داخل الصفحات لا تطابق اسم الرابط المرسل: Luna Master تعرض مكتب ياسر العدوي، Ayada Clinic تعرض Care Dental Center، وStudio Kayan Design تعرض Rihal Travel Studio. تُظهر البطاقات الاسم الظاهر في الموقع لتفادي التناقض.
- لا تُدرج أسعارًا أو باقات أو شهادات عملاء ما لم يقدّم المستخدم تفاصيل وأسعارًا وآراء موثقة لاحقًا.
- يُحفظ اختيار EN/AR في `localStorage` تحت المفتاح `qutoof-language`.
