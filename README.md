# Qutoof Solutions — قطوف للحلول الرقمية

موقع صفحة واحدة، سريع ومتجاوب، بواجهتين EN/AR. يستخدم Vite للبناء، وLenis للتمرير السلس، وMotion (واجهة DOM من منظومة Framer Motion) للحركة المتدرجة. لا يحتاج الموقع إلى خادم خلفي أو قاعدة بيانات.

## التطوير والبناء

```bash
npm ci
npm run dev
npm run build
npm run preview
```

يفتح خادم التطوير على المنفذ 3000. ملفات الناتج الثابتة في `dist/`، وملف بيان المسارات المصدر في `public/manus-routes.json`.

## بنية الملفات

- `assets/images/logo.png` — الشعار المرفق كما هو.
- `css/main.css` — لوحة العلامة والتصميم المتجاوب وRTL.
- `css/animations.css` — الكشف والحركة.
- `js/main.js` — سلوك الصفحة والنماذج.
- `js/lang.js` — المحتوى الإنجليزي والعربي ومبدل اللغة.

## نقاط يجب اعتمادها قبل النشر العام

- رابط WhatsApp حاليًا يستخدم قناع الرقم الوارد في موجز العمل `9665XXXXXXXX`. استبدل قيمة الثابت `WHATSAPP_PHONE` في `js/main.js` برقم قطوف السعودي الفعلي بصيغة wa.me من دون `+` أو مسافات؛ روابط WhatsApp ومراسلة النموذج تستخدم هذا المصدر المركزي عند تشغيل JavaScript. حدّث كذلك روابط wa.me الاحتياطية الظاهرة في `index.html` حتى يبقى الرابط صحيحًا قبل تحميل JavaScript، واستبدل نص الترحيب العربي إذا تغيّر.
- معرض الأعمال ومؤشراته تصورات مرئية وأرقام توضيحية، وليست نتائج أعمال أو بيانات عملاء موثقة. حدّثها من `js/lang.js` بمشاريع ومؤشرات معتمدة قبل الإعلان عنها.
- نصوص آراء العملاء تجريبية عمدًا؛ لا تنسبها إلى عملاء حقيقيين. استبدلها بتقييمات موثقة وبموافقة أصحابها قبل الإطلاق.
- الأسعار المعروضة (3,900 / 7,900 / 12,900 ر.س كبدايات) اقتراحات أولية للنقاش؛ ثبّت التسعير الفعلي ونطاق الباقات والضرائب قبل الإطلاق.
يُحفظ اختيار EN/AR في `localStorage` تحت المفتاح `qutoof-language`.
